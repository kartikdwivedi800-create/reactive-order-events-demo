# reactive-order-events-demo
Demo: Spring Boot WebFlux + Kafka reactive order-evets pipeline (learning/testing project)

## Demo

A tiny dependency-free Node project showing reactive order events.

- `src/eventBus.js` – publish/subscribe bus
- `src/orderService.js` – order state machine that emits events
- `npm start` runs the demo, `npm test` runs the tests
